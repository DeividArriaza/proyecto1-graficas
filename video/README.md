# Video de la entrega

Colocar acá la grabación del juego corriendo.

Sugerencia de nombre: `lethal-maze.mp4`.

## Qué conviene mostrar

En orden, para que el video cubra todo lo que se puede evaluar:

1. **Pantalla de bienvenida** — recorrer las opciones con `W`/`S` para que se vea
   que hay tres niveles y el modo infinito.
2. **Un nivel fijo** — caminar, girar con el mouse, correr con `Shift`.
3. **La linterna** — apagarla con `M` y quedarse a oscuras unos segundos, después
   prenderla. Es lo que muestra el modelo de iluminación.
4. **El minimapa** — llenándose conforme se explora.
5. **El contador de FPS** — visible todo el tiempo, arriba a la izquierda.
6. **El monstruo** — alumbrarlo de lejos, verlo caminar, y dejarse atrapar para
   que aparezca la pantalla de derrota.
7. **Un nivel completo hasta la salida** — para la pantalla de éxito con el
   informe.
8. **El menú de pausa** — con `Esc`, ajustando el volumen de la música.
9. **El modo infinito** — entrar dos veces para que se vea que el laberinto
   cambia.

## Notas

- Grabar **con audio**: la música y los efectos son parte de lo que se entrega.
- Si el archivo pesa demasiado para el repositorio, subirlo a un enlace y dejar
  la dirección en el `README.md` de la raíz.
